# 备课知识库

这是你自己的备课资料库。备课 Skill 每次都会先读这里，备出来的课会越来越贴合你和你的班级。

## 怎么放资料

| 文件夹 | 放什么 |
|---|---|
| `00-我的档案.md` | 你的学科、年级、教材版本、教学风格（**先填这个**） |
| `01-班级学情/` | 每个班一个文件 |
| `02-课标与教材/` | 课标原文、教材、教参、单元规划 |
| `03-我的教案/` | 以前写的教案 |
| `04-教学反思/` | 课后反思 |
| `05-评课意见/` | 磨课意见、专家点评、比赛评分标准 |
| `06-素材库/` | 导入素材、案例、习题、视频链接 |
| `07-优秀课例/` | 名师课例、看过的好课笔记 |

- Word、PDF、图片、Markdown 都可以直接丢进来，不用整理格式。
- 扫描版 PDF 和图片可能读不全，重要内容最好粘贴成文字。
- 学生信息请用代号，不要写真实姓名。

## 放在哪

默认放在 `~/备课知识库/`（用户主目录下）。也可以放在别处，备课时告诉 Claude 路径就行。
