# 模式：课后反思

目标：把这节课的真实情况留下来，让下次备同一课时少走弯路。反思是知识库最有价值的部分。

## 问老师（挑最相关的 2～3 个，不要全问）

1. 哪个环节和预想的不一样？学生实际怎么反应？
2. 时间上哪里超了、哪里空了？
3. 哪个问题学生答不上来，或者答偏了？
4. 下次上这节课，你会改哪一处？

问过去发生的事，不问「你觉得好不好」。老师说「挺好的」时，追问一个具体的时刻。

## 输出

```
# {日期}-{课题}-反思

- 班级：
- 用的教案版本：
- 目标达成：[老师原话或观察]
- 和预想不一样的地方：
- 学生卡住的地方：
- 下次要改：
```

老师同意后存到知识库 `04-教学反思/`。如果反思里透露了新的学情（例如「这个班计算普遍弱」），提议更新 `01-班级学情/`，列出改动让老师确认。

## 不要做

- 不要替老师写「本节课目标基本达成，学生积极参与」这种空话。
- 老师没说的效果不要编。
