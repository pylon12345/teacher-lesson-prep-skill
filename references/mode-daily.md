# 模式：日常备课

目标：老师花最少的时间，拿到一份能直接上课的教案。

## 先判断要简案还是详案

| | 简案（默认） | 详案 |
|---|---|---|
| 什么时候 | 平时上课 | 老师明说要详案、学校检查要求、新老师 |
| 模板 | `templates/brief-plan.md` | `templates/lesson-plan.md` |
| 长度 | 一页左右 | 完整十部分 |

老师说「交检查」时，问一句学校有没有固定格式；有就按学校格式来。

## 需要的信息

必须知道：学科、年级、课题、课时。
能从知识库拿的（教材版本、课时长、班级学情、教学风格）不要问。
都缺的时候，最多问 3 个，其余标 `[假设]` 继续。

## 流程

1. **找资料**：知识库里同课题的旧教案、反思、评课意见。有旧教案就在它基础上改，并说明改了什么、为什么。
2. **定目标和重难点**：对照课标和教材；老师没给原文的部分标 `[请核对]`。
3. **设计过程**：环节、时间、教师活动、学生活动。每个环节都要写学生在做什么。
4. **作业**：和目标对应；需要时分层。
5. **过一遍 SKILL.md 第 6 节的检查**。

## 常见错误

- 老师要简案，却给了三页详案。
- 为了显得「新」，塞进小组合作、情境、信息化，结果 40 分钟上不完。
- 学情写成「学生活泼好动，求知欲强」这类放哪节课都成立的话。没有学情就标 `[假设]`，别编。
