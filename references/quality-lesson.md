# 优质课：流程与通用评价维度

## 正常顺序

1. **定课题**：按比赛要求选课或抽签。
2. **研读课标**：本课对应的课标要求与核心素养。
3. **研读教材**：单元地位、前后联系、编者意图。
4. **分析学情**：学生基础、难点、特点。
5. **收集资料**：名师课例、教学设计、素材。
6. **写教学设计**：初稿 v1。
7. **做课件、教具、学习单**。
8. **第一轮试讲**：教研组听课。
9. **听评课 → 修改**：出 v2。
10. **多轮试讲**：通常 3～5 轮，每轮打磨导入、过渡语、提问、时间分配、学生回答预设。
11. **定稿**：教学设计 + 课件 + 逐字稿。
12. **说课稿**及其他比赛材料。
13. **正式上课**。
14. **课后反思**。

## 通用评价维度（没有评分表时用）

各地评分表不同，拿到正式评分表一律以评分表为准。

| 维度 | 看什么 |
|---|---|
| 教学目标 | 符合课标和学情，具体可测，体现核心素养 |
| 教材处理 | 重难点准确，有取舍、有整合，突破方法得当 |
| 教学过程 | 环节清楚、过渡自然、层层递进，时间分配合理 |
| 学生主体 | 学生活动充分，有思考、有合作、有展示，参与面广 |
| 提问设计 | 问题有梯度、有思维含量，给足思考时间 |
| 教学方法 | 方法多样且服务于目标，信息技术用得恰当 |
| 教师素养 | 语言准确精炼、有感染力，板书规范，应变能力 |
| 教学效果 | 目标达成度高，学生有收获，课堂有亮点 |

## 磨课常见问题

- 导入太长，超过 5 分钟
- 教师讲得多，学生活动少
- 提问太碎、太简单，或只有「对不对」「是不是」
- 过渡生硬，环节之间没有逻辑
- 前松后紧，最后没时间小结和练习
- 课件太花，喧宾夺主
- 预设太死，学生答偏了接不住
