# 教学目标常用行为动词

写目标时用可观察、可检测的动词，少用「了解、理解、掌握」这类没法检查的词。

| 层次 | 常用动词 |
|---|---|
| 识记 | 说出、写出、背诵、列举、识别、辨认、复述 |
| 理解 | 解释、说明、概括、区分、比较、举例、归纳 |
| 应用 | 运用、计算、解决、设计、制作、演示、操作 |
| 分析 | 分析、推断、分类、对比、找出、论证 |
| 评价 | 评价、判断、质疑、辩论、鉴赏 |
| 创造 | 创作、编写、提出、构建、改编 |
| 情感态度 | 体验、感受、关注、认同、养成、乐于 |

## 示例

- ❌ 理解三角形内角和定理。
- ✅ 通过剪拼、测量等活动，能说出三角形内角和是 180°，并用它求出未知角的度数。
